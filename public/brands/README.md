# Brand artwork

These original assets identify the platforms connected in Auren.
They are stored locally to avoid runtime requests to external brand websites.
Do not recolor, redraw, distort, or apply image filters to the artwork.

| Local file | Source |
| --- | --- |
| `tradesea.svg` | https://tradesea.ai/icons/logos/tradesea_tm_logo_nav.svg |
| `tradingview-black.svg` | `Logotypes/SVG/Black/full-logo-black.svg` from https://s3.tradingview.com/pub/TradingView-media-kit.zip |
| `tradingview-white.svg` | `Logotypes/SVG/White/full-logo-white.svg` from https://s3.tradingview.com/pub/TradingView-media-kit.zip |

The TradingView archive is linked by the official media kit:
https://www.tradingview.com/media-kit/.

Tradesea artwork uses a neutral dark plate for contrast. TradingView
uses the original black or white variant for the current theme. Brand names and
logos belong to their respective owners; display does not imply endorsement.
